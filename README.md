<details>
<summary><b>Drawer 05 · Bench rules</b> &nbsp;<sub>taped to the shelf above the soldering iron</sub></summary>

<br />

1. Measure it before you optimise it.
2. Pick the simplest architecture that survives contact with reality.
3. If nobody can use it, it isn't finished.
4. Do it by hand twice, then script it.
5. Write down what the next person needs to rebuild it.
6. Open by default.
7. If you want to understand it, make it.

</details>
